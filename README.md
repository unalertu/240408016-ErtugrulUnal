# Bean Corner Coffee

## Theme

This project is a website for a small coffee shop. It shows the shop, menu, and contact form.

## File Organization

- `index.html` is the home page.
- `about.html` tells the story of the shop.
- `services.html` shows the menu in a table.
- `contact.html` has a contact form.
- `assets` contains the images.

## Challenges

The main challenge was linking all four pages. I also learned how to make a table and a form with HTML.
